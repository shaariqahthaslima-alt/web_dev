# Eduford University Website

Eduford is a clean, modern, and responsive educational website template. It is designed for universities, colleges, and schools to showcase their campus, courses, facilities, and student life.

## 🚀 Features

- **Responsive Design:** Looks great on mobile, tablet, and desktop devices.
- **Course Listings:** Detailed information about various programs and courses offered.
- **Campus Facilities:** Sections highlighting infrastructure, libraries, and labs.
- **Student Reviews:** Testimonials and feedback from students.
- **Contact Section:** Get-in-touch form and location details for prospective students.

## 🛠️ Built With

- **HTML5** - For structuring the web pages.
- **CSS3** - For styling, layouts, and responsive media queries.
- **JavaScript** - For interactive elements (like navigation menus).
